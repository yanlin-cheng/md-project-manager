# 快速上手指南

3 步开始使用 MD 项目管理 Skill。

## 第一步：安装 Skill

将 `skill/` 目录复制到你的 Skill 目录：

### 用户级安装（推荐）

```
~/.codebuddy/skills/md-project-manager/
```

### 项目级安装

```
.codebuddy/skills/md-project-manager/
```

## 第二步：安装 Typora 高亮样式（可选）

如果你使用 Typora 编辑器，运行 `examples/typora-highlight.ps1` 脚本：

1. 右键点击 `typora-highlight.ps1`
2. 选择"使用 PowerShell 运行"
3. 等待脚本执行完成
4. 重启 Typora

**效果**：
- 高亮颜色从刺眼的黄色改为柔和淡蓝色
- 脚注链接改为深蓝色，便于识别

## 第三步：开始使用

### 创建项目文档

1. 复制 `templates/project-template.md` 到你的项目管理目录
2. 重命名为你的项目名称，如 `桌号牌项目.md`
3. 填写项目概述、进展日志等内容

### 创建项目管理面板

1. 复制 `templates/dashboard-template.md` 到你的项目管理目录
2. 重命名为 `A项目管理.md`
3. 在表格中添加你的项目

### 记录项目进展

在项目文档中添加新的日期条目：

```markdown
### 2026-05-06
今天把样品给客户看了，他们说大体还行，就是颜色要改改。
```

### 触发 AI 优化

告诉 AI：

```
帮我优化今天的日志
```

或：

```
检查一下哪些文件有变动
```

AI 会自动：
1. 识别口语化表达，润色为规范语言
2. 添加高亮标记和脚注
3. 更新项目管理面板

## 常见问题

### Q: 如何查看所有项目进度？

打开 `A项目管理.md`，查看项目概览表格。

### Q: 如何让 AI 优化特定内容？

在需要优化的内容前添加 `<!-- AI: 优化语言 -->` 标记。

### Q: 如何安装到其他编辑器？

让 AI 根据 Typora 的实现例子，自动适配其他编辑器。告诉 AI：

```
帮我把高亮样式安装到 Obsidian
```

AI 会自动检测你的编辑器环境，然后实现对应的样式。
