# MD 项目管理 Skill

一套简洁的 Markdown 项目管理规范，让 AI 能够自动更新项目日志、优化语音输入内容、维护项目管理面板。

## 核心优势

**单文件分发** - 只需复制一个 SKILL.md 文件即可使用，所有模板和示例已内化到技能文件中。

## 功能特性

1. **智能引导**：首次使用时自动引导创建项目文档体系
2. **自动优化**：将口语化表达润色为规范文档语言
3. **进度追踪**：自动同步项目进展到管理面板
4. **模板内置**：包含完整的模板和示例，开箱即用
5. **跨目录管理**：支持项目文档分散在不同目录、不同盘符

## 快速开始

### 1. 安装 Skill

将 `skill/SKILL.md` 复制到你的 Skill 目录：

- **用户级**（推荐）：`~/.codebuddy/skills/md-project-manager/SKILL.md`
- **项目级**：`.codebuddy/skills/md-project-manager/SKILL.md`

### 2. 开始使用

1. 告诉 AI："帮我创建项目管理面板"
2. AI 会引导你创建主控文档和第一个项目文档
3. 开始记录项目进展，让 AI 帮你优化和管理

## 目录结构

```
md-project-manager/

    └── SKILL.md           # Skill 定义文件（包含所有模板和示例）
```

## 使用示例

### 场景 1：从零开始

```
用户：我想开始管理我的项目
AI：好的，我将为您创建项目管理面板。请告诉我您有哪些项目需要管理？
```

### 场景 2：记录进展

```markdown
### 2026-05-06
今天把样品给客户看了，他们说大体还行，就是颜色要改改。
```

告诉 AI："帮我优化今天的日志"

AI 会自动：
1. 识别口语化表达，润色为规范语言
2. 添加高亮标记和脚注
3. 更新项目管理面板

### 场景 3：查看进度

打开 `项目管理面板.md`，查看所有项目的概览表格。

### 场景 4：跨目录管理

当项目文档分散在不同位置时：

```markdown
| 项目名称 | 优先级 | 完成度 | 最新状态 | 详细日志 |
|----------|--------|--------|----------|----------|
| 项目A | 高 | 60% | 进行中 | [查看日志](file:///D:/项目A/README.md) |
| 项目B | 中 | 30% | 规划中 | [查看日志](file:///E:/项目B/README.md) |
| 项目C | 低 | 10% | 已完成 | [查看日志](https://github.com/user/repo) |
```

告诉 AI："更新项目进度"，AI 会自动：
1. 读取主控文档中的链接
2. 按链接访问项目文档
3. 提取关键信息并更新主控文档

## 编辑器支持

本 Skill 使用标准 Markdown 语法，兼容所有支持 Markdown 的编辑器：

- **Typora**（推荐）：所见即所得，体验最佳
- **Obsidian**：支持双向链接，适合知识管理
- **VS Code**：配合 Markdown 插件，功能强大
- **Logseq**：大纲式编辑，适合思维整理

## 跨目录管理方案

当项目文档分散在不同目录、不同盘符、甚至不同电脑时：

### 方案一：绝对路径链接

在主控文档中使用绝对路径链接：

```markdown
| 项目名称 | 链接 | 最新状态 |
|----------|------|----------|
| 项目A | [查看](file:///D:/项目A/README.md) | 进行中 |
| 项目B | [查看](file:///E:/项目B/README.md) | 规划中 |
```

### 方案二：相对路径 + 符号链接

在主控文档目录创建符号链接指向实际项目：

```bash
mklink /D "项目A" "D:\实际路径\项目A"
```

### 方案三：定期同步

写一个脚本，定期将项目文档的关键信息同步到主控文档。
